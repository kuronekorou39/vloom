Vloom プライバシーポリシー・免責事項

最終更新: 2026年9月15日

Vloom は、あなたのデータを開発者に送りません。そもそもネットワーク通信を行いません。アカウント登録もありません。送受信したファイルと履歴は、すべてお使いの端末の中だけに保存されます。開発者がそれらを保存するサーバーは存在しません。

1. アプリの性質

Vloom は、片方の端末の画面にコードの動画を表示し、もう片方の端末のカメラで撮ることで、通信経路を一切介さずにファイルを渡すアプリです。Wi-Fi・Bluetooth・インターネットのいずれも使いません。

2. 開発者が収集する情報

ありません。

  • アカウント登録・ログイン機能はありません。氏名・メールアドレス等をお預かりすることはありません。
  • 送信するために選んだファイル、受信したファイル、受信履歴は端末内にのみ保存されます。
  • アプリはネットワークに接続しません。利用状況を収集する分析ツール (アナリティクス) や広告 SDK は組み込んでいません。
  • クラッシュレポートの自動送信も行いません。

3. 端末の権限とその用途

  • カメラ … 相手の画面に表示されたコードを読み取ってファイルを受信するために使います。撮影した映像は読み取りにだけ使い、保存も送信もしません。
  • マイク … 使用しません。カメラ機能のライブラリが宣言を必要とするため記載があるだけで、音声を取得することはありません。
  • ファイル … 送信するファイルを選ぶとき、および受信したファイルを保存・共有するときに、OS のファイル選択画面を通じてアクセスします。ユーザーが選んだファイル以外には触れません。

いずれの権限も、許可しない場合は対応する機能が使えなくなるだけで、それ以外の機能は引き続き利用できます。

4. データの保存場所と削除

受信したファイルと履歴は、アプリ専用の領域に保存されます。履歴画面から個別に削除できます。アプリをアンインストールすると、これらのデータはすべて端末から消えます。

5. 第三者への提供

データを開発者が取得していないため、第三者へ提供することもありません。

6. オープンソース

Vloom のソースコードは GitHub で MIT ライセンスのもとに公開しています。本ポリシーの内容は、コードで確認できます。

7. 免責事項

  • Vloom は現状有姿で提供されます。転送の成否・速度・所要時間は、画面とカメラの性能、周囲の明るさ、距離や角度などの環境に左右されます。
  • 転送に失敗した場合や、転送したデータの利用によって生じた損害について、開発者は責任を負いません。
  • コードは目視できる形で画面に表示されるため、周囲の人や他のカメラからも読み取れる可能性があります。人目のある場所で機密性の高いファイルを送る際はご注意ください。
